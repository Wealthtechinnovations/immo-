# Contribuer à COICA

1. Lire `00_START_HERE.md` et les autorités de `.governance/`.
2. Partir du HEAD de `Server` ; branche `feat|fix|docs/coica-<lot>-<objet>`.
3. Une PR doit référencer la tâche, son scope, les preuves/tests et les risques.
4. Ne pas modifier les sources institutionnelles ou leurs statuts sans preuve citée et vérifiable.
5. Ne jamais committer secret, jeton, donnée personnelle de test réelle ou export foncier non autorisé.
6. Avant merge : validation gouvernance, tests du composant, revue diff et mise à jour checkpoint/handoff.
7. Un changement de modèle légal exige test négatif des invariants dans `LEGAL_INVARIANTS.md`.
