# COICA — Côte d’Ivoire Land Intelligence & Claim of Interest

**Statut : programme défini, aucun service applicatif déployé.** Dépôt cible : Wealthtechinnovations/immo- ; branche de référence constatée : Server.

COICA est une plateforme de cartographie foncière et de déclarations d'intérêt, fédérant des sources urbaines, rurales, géographiques et satellitaires via des connecteurs MCP. L'absence d'un lotissement identifié ne vaut **jamais** disponibilité foncière ou droit de propriété.

## Règle d'or
**NO_DATA ≠ FREE_LAND ; NOT_LOTTED ≠ PURCHASABLE ; CLAIM ≠ TITLE.**

Aucun accès institutionnel n'est garanti. Les sources publiques ne constituent pas une autorisation automatique de scraping ou de redistribution. Les livrables de cette baseline sont uniquement documentaires et de coordination ; pas de code applicatif.
