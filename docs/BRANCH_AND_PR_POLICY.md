# Branch & PR policy

`Server` est la branche d'intégration constatée. Pas d'écriture applicative directe dessus pendant le développement gouverné. Une PR = un lot ou une unité cohérente. Les branches parallèles ne doivent pas revendiquer les mêmes fichiers/domaines. Les statuts CI sont nécessaires lorsqu'un workflow applicable existe. La fusion ne transforme pas automatiquement une tâche en DONE : l'état canonique doit être mis à jour dans la même unité de livraison ou un commit de clôture explicitement relié.
