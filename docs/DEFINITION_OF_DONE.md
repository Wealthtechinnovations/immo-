# Definition of Done

Une tâche n'est DONE que si son contrat est précis, le scope respecté, les tests/validations passent, le diff est relu, les risques connus sont documentés, les données gardent leur provenance, aucun invariant foncier n'est violé, la documentation utile est mise à jour et checkpoint/handoff désignent une reprise cohérente. Pour les sources externes : droits et capacité technique sont deux gates distinctes.
