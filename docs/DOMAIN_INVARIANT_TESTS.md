# Tests invariants

Tests obligatoires : création claim ne crée ni owner/title/right ; OFFICIALLY_CONFIRMED sans evidence légale vérifiée est refusé ; données sans provenance sont rejetées aux frontières d'ingestion ; paiement ne modifie pas claim en ownership ; observation satellite n'est jamais convertie en droit ; absence de résultat source produit UNKNOWN/INSUFFICIENT_DATA selon couverture, jamais AVAILABLE.
