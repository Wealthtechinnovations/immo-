# Protocole de découverte

Pour chaque source : identifier propriétaire/autorité, URL officielle, conditions/licence, authentification, surfaces documentées, formats, géométrie, pagination, quotas, cadence, données personnelles, historique et mécanisme de changement. Enregistrer preuves et date. Ne pas sonder des interfaces privées, contourner protections ou déduire des droits d'un simple HTTP 200.

Transitions : DISCOVERY→PUBLIC_WEB/OPEN_CANDIDATE/PARTNERSHIP_REQUIRED ; puis, séparément, `technical_access`, `reuse_authorization`, `geometry_access`, `automation_authorization`. Seul un ensemble compatible permet ingestion.
