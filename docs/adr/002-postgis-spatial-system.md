# ADR-002 — PostgreSQL/PostGIS comme système spatial interne

**Décision : acceptée sous validation environnementale L04.** Le modèle canonique spatial vise PostgreSQL/PostGIS pour géométries, index et opérations topologiques. Les sources restent autoritatives dans leur propre périmètre ; PostGIS stocke observations/version/provenance, pas une vérité juridique inventée.
