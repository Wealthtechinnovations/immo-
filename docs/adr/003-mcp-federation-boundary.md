# ADR-003 — MCP comme frontière de fédération

**Décision : acceptée.** Un gateway expose des capacités normalisées ; chaque connecteur traduit une source vérifiée. MCP ne crée ni droit d'accès ni donnée. Les connecteurs doivent pouvoir être désactivés et échouer fermés. Le domaine ne dépend pas d'un endpoint institutionnel particulier.
