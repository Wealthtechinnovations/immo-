# L00 — Bootstrap et gouvernance agents

Objectif : rendre le dépôt auto-descriptif et vérifiable par un agent sans historique conversationnel. L00 ne donne aucun droit d'accès à une source externe et ne remplace pas GitHub comme arbitre des commits/PR.

## Contrat
Entrée : baseline COICA v1 fusionnée. Sortie : schémas de gouvernance, validation locale/CI, contrats de tâches détaillables, conventions branches/PR, modèle de claim non transactionnel explicitement limité, Definition of Done et runbook de reprise.
