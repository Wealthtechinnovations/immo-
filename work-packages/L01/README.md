# L01 — Architecture et ADR

Objectif : figer les frontières de composants et contrats structurants avant le code métier. L'architecture est modulaire, source-agnostique et provenance-first.

Sortie : ADR 001–006, architecture logique, règles de dépendances et critères de sélection de stack. Aucun choix de fournisseur externe n'est présenté comme acquis.
