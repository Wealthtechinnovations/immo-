# L06 SIGFU — adaptateur sûr en mode découverte

L'interface publique SIGFU ne constitue pas une autorisation automatique de collecte. Aucun endpoint non documenté, scraping, ni contournement n'est implémenté. Le connecteur reste désactivé tant que licence, capacités, géométries et automatisation ne sont pas vérifiées. Le code fournit uniquement le contrat d'adaptateur et ses tests négatifs.
